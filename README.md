# Piply

Piplyは、Macで開いているアプリのウィンドウやChromeのタブを、常に手前に表示できるピクチャ・イン・ピクチャ（PiP）アプリです。

## 動作環境

- macOS 14以降
- Chromeタブ連携を使う場合はGoogle Chrome 116以降

## 開発と配布

Chrome拡張機能の開発用コードは、役割ごとに `ChromeExtension` 内の複数のJavaScriptファイルへ分けています。配布版は次のコマンドで作成できます。

```sh
node scripts/build-chrome-extension.mjs
```

生成先は `dist/ChromeExtension` です。配布版ではJavaScriptが `piply.js` の1ファイルにまとめられ、そのフォルダをChromeの「パッケージ化されていない拡張機能を読み込む」でそのまま選べます。

アプリとChrome拡張機能をまとめた配布用ZIPは、アプリをビルドした後に次のコマンドで作成できます。

```sh
./scripts/package-release.sh
```

生成先は `release` です。公開リポジトリには、Xcodeの個人用設定、ビルド生成物、開発者証明書で署名されたアプリ、録画・スクリーンショットを含めないでください。配布スクリプトはZIP内のアプリを個人情報を含まないアドホック署名へ置き換えます。一般公開でmacOSの警告を出さずに配布する場合は、公開者のDeveloper IDによる署名とAppleの公証が別途必要です。

## はじめに

1. `Piply.app` を開きます。
2. 初回に画面収録の許可を求められたら、「システム設定」→「プライバシーとセキュリティ」→「画面とシステムオーディオ録音」でPiplyを許可します。
3. Piplyをいったん終了し、もう一度開きます。
4. 一覧から表示したいウィンドウを選び、「PiPで表示」を押します。

ウィンドウ一覧が更新されないときは、右上の「再読み込み」を押してください。

## 基本操作

### ウィンドウをPiPで表示する

Piplyの一覧には、現在開いているアプリのウィンドウが表示されます。

- 「PiPで表示」をクリックすると、新しいPiPウィンドウで表示します。
- ボタン右側のメニューから「新しいPiPタブに追加」を選ぶと、既存のPiPにタブとして追加します。
- 複数のPiPウィンドウを同時に表示できます。

### フォーカス中のアプリをすぐに表示する

表示したいアプリを手前にした状態で `Shift + Command + P` を押すと、そのアプリの最前面ウィンドウをPiPで表示します。

メニューバーのPiplyアイコンから「フォーカス中のアプリをPiP」を選ぶこともできます。Chromeでは、個別のタブではなくChromeウィンドウ全体が表示されます。

### PiPウィンドウを操作する

- ドラッグして移動できます。
- ウィンドウの端をドラッグすると、縦横比を保ったままサイズを変更できます。
- PiPにポインタを重ねると、固定ボタンと閉じるボタンが表示されます。
- 固定ボタンを押すと、PiPの位置を動かないようにできます。
- PiPは通常のデスクトップだけでなく、別のSpaceや他のアプリのフルスクリーン画面にも表示できます。

一部のフルスクリーン表示や保護されたコンテンツでは、PiPが表示されなかったり、映像が黒くなったりすることがあります。

## PiPタブを使う

1つのPiPウィンドウに複数の表示元をまとめ、タブで切り替えられます。

- タブ名をクリックすると表示を切り替えます。
- 「＋」を押すと、別のウィンドウやChromeタブを追加できます。
- タブにポインタを重ねて「×」を押すと、そのタブを閉じます。
- タブを右クリックすると、左右への移動、削除、別のPiPウィンドウへの移動ができます。
- タブを別のPiPウィンドウへドラッグすると、そのPiPへ移動できます。
- タブをPiPの外へドラッグすると、独立したPiPウィンドウに分けられます。
- タブが横幅に収まらないときは、トラックパッドやマウスホイールで横にスクロールできます。

Piplyを終了すると、開いていたPiPタブの構成は破棄されます。

## Chromeのタブや動画を表示する

Chrome拡張機能を追加すると、ブラウザのタブバーやアドレスバーを含めず、選んだタブだけをPiPで表示できます。Chrome上の動画だけを表示し、PiP内から再生操作を行うこともできます。

### Chrome拡張機能を設定する

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、Piplyに付属する `ChromeExtension` フォルダを選びます。
4. 追加されたPiply拡張機能の32文字のIDをコピーします。
5. Piplyの「設定」→「Chrome タブ連携」にIDを貼り付け、「連携を設定」を押します。
6. `chrome://extensions` に戻り、Piply拡張機能の再読み込みボタンを押します。
7. Piplyの設定画面に「Chrome 拡張機能と接続済み」と表示されたら準備完了です。

拡張機能を更新した場合も、`chrome://extensions` でPiply拡張機能を再読み込みしてください。

### Chromeタブ全体を表示する

Piplyの一覧で「Chromeのタブ」を開き、表示したいタブの「PiPで表示」を押します。

初めて表示するタブや休止中のタブでは、Piplyが対象のタブをChromeで開きます。その後、ChromeのツールバーにあるPiply拡張アイコンを1回押してください。

現在Chromeで開いているタブは、Piply拡張アイコンを押して直接PiPに送ることもできます。

### 動画だけを表示する

1. Chrome上の動画を右クリックします。
2. 「動画をPiPで表示」または「動画を新しいPiPタブに追加」を選びます。

ページ独自の右クリックメニューが表示される場合は、もう一度右クリックしてChromeのメニューを開いてください。

動画PiPにポインタを重ねると、次の操作が表示されます。

- 10秒戻す／10秒進む
- 再生／一時停止
- 再生位置の変更
- 消音／消音解除

音声は元のChromeから再生されます。元のタブを閉じるか、PiPタブの「×」を押すと接続を終了します。

## 設定

Piply右上の「設定」、またはメニューバーのPiplyアイコンにある歯車ボタンから設定画面を開けます。

- **言語**：日本語または英語を選べます。
- **テーマ**：白、黒、水色、黄色、ピンクから選べます。Piply本体、設定画面、メニューバー、PiPに反映されます。
- **タブバー**：「上部に常時表示」または「ホバー時に映像へ重ねる」を選べます。
- **Chrome タブ連携**：Chrome拡張機能との接続を設定できます。
- **Macへのログイン時に自動起動**：Macへのログイン時にPiplyを起動できます。

Piplyのメインウィンドウを閉じても、アプリはバックグラウンドで動作します。完全に終了するには、メニューバーのPiplyアイコンから「終了」を選ぶか、`Command + Q` を押してください。

## うまく表示できないとき

### 画面収録の許可が表示される

「システム設定」→「プライバシーとセキュリティ」→「画面とシステムオーディオ録音」でPiplyを許可し、Piplyを再起動してください。

### Chrome拡張機能と接続できない

- Piplyの設定に入力した拡張機能IDが正しいか確認します。
- `chrome://extensions` でPiply拡張機能を再読み込みします。
- PiplyとChromeを再起動します。

### Chromeの映像が暗い、または黒い

Chromeの「設定」→「システム」で「グラフィック アクセラレーションが使用可能な場合は使用する」をオフにし、Chromeを再起動すると改善する場合があります。オフにすると動画の再生性能が低下することがあります。

### Chrome動画を表示できない

- 動画を一度再生してから、もう一度試してください。
- ページを移動した後は、動画を右クリックして再接続してください。
- Chromeの内部ページ、アクセスできないシークレットウィンドウ、埋め込み方法によって取得できない動画には対応していません。
- NetflixやPrime VideoなどのDRM保護動画は表示できません。

## ご利用上の注意

- パスワード画面やDRM保護動画など、保護されたコンテンツは黒く表示されることがあります。
- PiP内から元のアプリを直接操作することはできません。動画PiPの再生操作のみ対応しています。
- 映像の滑らかさや画質は、Macの負荷や表示元の内容によって変わります。
- Chromeタブや動画の音声はPiplyへ移さず、Chromeから再生します。
